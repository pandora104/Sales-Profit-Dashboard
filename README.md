# Sales-Profit-Dashboard

## Project Overview
An Excel-based data analytics project focused on analyzing sales and profitability to understand business performance.

## Key Insights
- Total Sales and Total Profit
- Profit Analysis by Year
- Sales by Category
- Top Customers by Profit
- Customer Count by Year
- Sales Performance by State
- Monthly Sales Trends

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization
